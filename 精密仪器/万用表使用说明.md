# 万用表使用说明

本文档介绍**普通手持式数字万用表**的使用方法，重点讲解如何测量电压和电流，并附电阻、通断等常用功能和安全注意事项，供现场测量时参考。

---

## 1. 认识万用表

### 1.1 表盘档位（旋转开关）

| 档位符号 | 含义 | 用途 |
| --- | --- | --- |
| `V⎓` 或 `DCV` | 直流电压 | 测电池、电源、直流电路电压 |
| `V~` 或 `ACV` | 交流电压 | 测市电、变压器输出等交流电压 |
| `A⎓` 或 `DCA` | 直流电流 | 测直流回路电流 |
| `A~` 或 `ACA` | 交流电流 | 测交流回路电流 |
| `Ω` | 电阻 | 测电阻、判断线路通断 |
| `⏻` / `)))` | 通断/蜂鸣 | 测线路是否导通（导通时蜂鸣） |
| `-▶|-` | 二极管 | 测二极管、判断极性 |
| `F` / `H` | 电容 / 电感 | 测电容、电感（部分型号） |

> 部分万用表为**自动量程（Auto Range）**，无需手动选量程；手动量程的表需先选大档再逐步调小。

### 1.2 表笔插孔（黑红表笔怎么插）

万用表表笔是**香蕉插头**，把插头对准插孔**垂直插到底**即可，插紧后会感到卡住、不会松动。**黑表笔永远插 COM，红表笔随测量类型换孔**——这是最关键的一条规则。

#### 常见插孔布局

普通手持式万用表通常有 3~4 个插孔，从左到右大致为：

```
┌──────────────────────────────────────┐
│   10A/20A    mA/μA    COM    VΩHz      │   ← 表笔插孔
│   (大电流)   (小电流)  (公共)  (电压/   │
│                              电阻/通断) │
└──────────────────────────────────────┘
```

不同型号孔的个数和标注略有差异（例如有的把 VΩ 和 mA 合成一个孔），但功能一一对应。

#### 红黑表笔分别插哪里

| 测量内容 | 黑表笔 | 红表笔 |
| --- | --- | --- |
| 电压（DCV / ACV） | **COM** | **VΩ**（V/Ω 孔） |
| 电阻 Ω | **COM** | **VΩ** |
| 通断 / 二极管 | **COM** | **VΩ** |
| 小电流（mA / μA） | **COM** | **mA** 或 **μA** 孔 |
| 大电流（10A / 20A） | **COM** | **10A** 或 **20A** 孔 |

要点：

- **黑表笔固定插 COM**，任何测量都不变。
- **红表笔默认插 VΩ 孔**（测电压、电阻、通断都用它）。只有测电流时才需要换到电流孔。
- 电流孔分**小电流（mA/μA）**和**大电流（10A/20A）**两个，按预计电流大小选择：先估算被测电流，超过 mA 孔量程就用 10A/20A 孔。
- 插好后**轻轻拉一下**确认插紧，避免接触不良导致读数跳动或测不出值。

#### 为什么插错会烧表

- 若用**电流档（红表笔插电流孔）去测电压**，万用表内部相当于一根近乎短路的导线，会把电源短路，轻则烧保险丝，重则损坏仪表甚至打火伤人。
- 因此每次换测量类型（电压 ↔ 电流）时，**必须同时改档位和红表笔插孔**，两者要一致。
- 用完电流档，**第一时间把红表笔插回 VΩ 孔**，防止下次误用。

#### 快速口诀

> **黑笔认准 COM，红笔平时插 VΩ；测电流才换孔，大电流用 10A。**

## 2. 使用前准备

1. 检查电池电量，显示屏无显示或显示异常时先更换电池。
2. 检查表笔是否完好、有无破损裸露，插头是否插紧。
3. **先选对档位和表笔插孔**，再接触被测电路。
4. 不确定被测值大小时，先选**最大量程**，再逐步调小到合适档位。

---

## 3. 测量电压（并联测量）

电压测量是**并联**在被测元件或电源两端。

### 3.1 直流电压（DCV）

1. 档位旋到 `V⎓`（DCV）。
2. 红表笔插 **VΩ** 孔，黑表笔插 **COM**。
3. **红表笔接正极，黑表笔接负极**，两笔并联在被测点两端。
4. 读取显示值，单位为 V。若显示负值，说明表笔极性接反，对调即可。

### 3.2 交流电压（ACV）

1. 档位旋到 `V~`（ACV）。
2. 表笔接法与直流相同，但**交流不分正负**，红黑表笔可任意接。
3. 读取显示值，单位为 V。

---

## 4. 测量电流（串联测量）

电流测量必须把万用表**串联**接入回路，这是与测电压最大的区别。

### 4.1 操作步骤

1. **先断开被测电路**（关电源或断开回路），否则串联瞬间可能打火或烧表。
2. 选好电流档位：`A⎓`（直流电流）或 `A~`（交流电流）。
3. **红表笔插入对应电流插孔**（小电流用 mA 孔，大电流用 10A/20A 孔），黑表笔插 COM。
4. 把万用表**串入断开的回路**中：电流从红表笔流入、从黑表笔流出。
5. 接通电源，读取显示值，单位为 A。

### 4.2 注意

- 测电流时**绝不可以把表笔直接并在电源两端**，否则相当于短路。
- 大电流测量时间要短（多数表 10A/20A 档只能短时测量），避免发热损坏。
- 测完电流后，**及时把红表笔从电流孔插回 VΩ 孔**，防止下次误用。

---

## 5. 测量电阻与通断

1. **必须先断开电路电源**，电路中不能带电，否则读数不准甚至损坏仪表。
2. 档位旋到 `Ω`（电阻）或通断档。
3. 红表笔插 VΩ 孔，黑表笔插 COM。
4. 两表笔分别接触被测电阻两端，读取阻值；通断档导通时蜂鸣器响。

---

## 6. 安全注意事项

- **量程与档位**：测电压/电流前先确认档位正确，电压表并接、电流表串接，切勿混淆。
- **电流档禁止并接电源**：用电流档直接测电压会短路、烧保险甚至损坏仪表。
- **电阻/通断档必须断电测量**。
- **高压安全**：测量市电或高压时，手不要接触表笔金属部分，站在绝缘处，单手持表笔操作。
- **量程从小往大**：未知电压/电流时先用最大量程，避免超量程。
- **测完归位**：测量结束后把旋钮转到 OFF 或最高电压档，红表笔插回 VΩ 孔，延长电池和仪表寿命。

---

## 7. 常见错误对照

| 现象 | 可能原因 |
| --- | --- |
| 电流读数一直为 0 | 表笔没插电流孔，或回路没串通 |
| 电压读数偏低/不稳定 | 表笔接触不良、量程过大 |
| 一测就跳闸/打火 | 用电流档并联测了电源两端 |
| 电阻读数异常 | 被测电路仍带电 |
| 显示 `1` 或 `OL` | 超出当前量程，需换更大量程 |

## 8. 测量 AI / AO / DI / DO 信号（黑红表笔接法）

在 PLC / DAQ 系统中，信号分为四类：

| 类型 | 名称 | 典型信号 |
| --- | --- | --- |
| **AI** | 模拟量输入 | 0~10V、±10V、4~20mA、0~20mA |
| **AO** | 模拟量输出 | 0~10V、±10V、4~20mA |
| **DI** | 数字量输入 | 24V DC 开关量（有/无） |
| **DO** | 数字量输出 | 24V DC 开关量（有/无） |

**总原则**：电压型信号**并联**测，电流型信号**串联**测；**黑表笔接参考端（地 / 负端 / 公共端），红表笔接信号端**。

### 8.1 AI（模拟量输入）

**电压型（0~10V / ±10V）：**

1. 档位选直流电压 `V⎓`（量程先用大档）。
2. 红表笔插 **VΩ**，黑表笔插 **COM**。
3. **黑表笔接信号地 / 负端**（AGND、0V、AI−），**红表笔接信号正端**（AI+）。
4. 两笔**并联**在信号两端，读取电压值。

**电流型（4~20mA）：**

1. 档位选直流电流 `A⎓`。
2. 红表笔插 **mA** 孔，黑表笔插 **COM**。
3. 必须**串联**接入信号回路：**断开 AI 信号线**，把万用表串进去。
4. **红表笔接电流流入端**（信号源 +），**黑表笔接流出端**（回到模块端）。
5. 读取电流值：4mA 对应量程下限、20mA 对应上限。

> 注意：4~20mA 电流信号**不能像电压那样并接测量**，并接相当于短路，读数错误还可能损坏回路。

### 8.2 AO（模拟量输出）

接法与 AI 完全一样，只是测的是模块的**输出**端：

- **电压型**：黑表笔接 AO 输出负端 / GND，红表笔接 AO+，并联测电压。
- **电流型**：把万用表串联在 AO 输出回路中，红表笔插 mA 孔，测输出电流。

### 8.3 DI（数字量输入）

DI 一般是 24V DC 开关量：

1. 档位选直流电压 `V⎓`，量程用 **20V 或更高**（建议先用大档）。
2. 红表笔插 **VΩ**，黑表笔插 **COM**。
3. **黑表笔接公共端 / 0V**（GND、COM、M 或 0V），**红表笔接 DI 输入点**。
4. 读电压：**有信号约 24V**（或模块标称电压），**无信号约 0V**。

> 注意：DI 有源型 / 漏型（PNP / NPN）之分，但**测量方法一样**——都是测输入点对公共端的电压。若不确定公共端在哪，先测 0V 与输入点之间的电压。

### 8.4 DO（数字量输出）

接法与 DI 相同：

1. 档位选直流电压 `V⎓`。
2. **黑表笔接 0V / 公共端**，**红表笔接 DO 输出点**。
3. 输出 **ON 约 24V**，**OFF 约 0V**。

### 8.5 通用注意

- **电压型信号**（AI/AO 的 0~10V、DI、DO）一律**并联**测量：黑笔接参考地、红笔接信号点。
- **电流型信号**（4~20mA 的 AI/AO）必须**串联**测量：红笔插 mA 孔，断开回路后串入。
- 先确认**参考点（公共端 / 地）**，再测信号点；电压档接反只会显示负值，不会烧表。
- 测电流信号务必**断电接线、确认串联无误后再上电**，切勿用电流档并接测电压。
- 数字量测量量程用**直流 20V 或更高**档，避免超量程。
