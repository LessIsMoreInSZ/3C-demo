# PCBase 学习教程与开发文档

本目录将 `PCBase` 定义为“基于工业 PC 的运动控制开发资料库”。它面向两类读者：

- 第一次接触运动控制卡、伺服、电机与 EtherCAT 的初学者
- 需要把运动控制项目真正做起来的上位机、设备控制、自动化开发工程师

本套资料默认以 `EtherCAT 总线伺服系统` 为主线来组织术语、开发流程和排障方法。脉冲型控制卡仍然会介绍，但整体学习路线优先围绕 `EtherCAT + CiA 402 + 远程 I/O` 展开。

本文档的目标不是罗列一堆型号，而是把“型号、术语、选型、开发、调试”串成一条完整学习路径。你可以把它当成一个从 0 到 1 的 PC-based Motion Control 入门仓库。

## 你可以从这里获得什么

- 看懂 **PC-based 运动控制系统**由哪些硬件和软件组成
- 区分 **脉冲型 / 模拟量 / EtherCAT / 网络型** 控制方案的适用边界
- 建立一条从 **术语 → 选型 → 建轴 → 回零 → 调试 → 交付** 的完整开发认知
- 形成适合新人上手、适合团队沉淀的 **统一排障语言和开发分层思路**

## 推荐学习路径

### 路线 A：零基础入门（1~2 周）

1. 先搞懂单轴的“使能 -> 回零 -> 点动 -> 定位 -> 停止 -> 报警复位”。
2. 再理解脉冲型控制和 EtherCAT 控制的差别。
3. 学会看电气图：限位、原点、急停、Servo ON、ALM、INP。
4. 学会做单位换算：脉冲、编码器计数、毫米、角度。
5. 配合术语表，把 EtherCAT、PDO、SDO、CiA 402、STO 等高频词逐个吃透。

### 路线 B：准备做第一台样机（2~4 周）

1. 选择控制架构：脉冲 / EtherCAT / 网络型控制器
2. 按 `04-开发文档` 设计分层与配置结构
3. 按 `07-EtherCAT限位回零与复位` 固化限位和回零策略
4. 按 `05-调试与排障清单` 制作现场 SOP 和验收清单
5. 最后回到 `02-常见运动控制卡型号与选型` 校正选型是否合理

### 路线 C：团队沉淀知识库

- 将 `04-开发文档` 作为架构规范模板
- 将 `05-调试与排障清单` 作为联调和现场复盘模板
- 将 `06-参考资料` 作为厂商资料入口

## PCBase 一句话理解

`PCBase = 工业 PC/工控机 + EtherCAT 主站/软运动平台 + 驱动器 + 电机 + 反馈 + 远程 I/O + 安全链 + 上位机软件`

和传统“只会做逻辑控制”的系统相比，PC-based 运动控制更强调以下能力：

- 多轴同步
- 轨迹规划
- 插补和跟随
- 与视觉、数据库、MES、上位机 UI 联动
- 更开放的软件架构和更强的算力

## 初学者最容易踩的坑

- 只看“轴数”，不看驱动方式、编码器接口、同步周期和 SDK。
- 只会调用 `MoveAbs`，但不理解回零、限位、使能、报警复位和单位换算。
- 把 Windows 上位机误当成硬实时控制器，不做线程隔离和异常联锁。
- 没有抽象轴、I/O、报警和配方，后续项目一改机型就要重写。
- 没有日志和状态机，现场故障无法复盘。

## 典型应用场景与选型建议

| 场景 | 更常见方案 | 原因 |
| --- | --- | --- |
| 2~4 轴、结构简单、预算敏感的小设备 | 脉冲型控制卡 | 成本和上手门槛较低 |
| 多轴联动、飞拍、视觉联动、扩展 I/O 多 | EtherCAT 主站 / 软运动平台 | 同步与扩展性更好 |
| 需要减少插卡依赖、希望布线更灵活 | 网络型运动控制器 | 拓扑更灵活 |
| 老设备升级改造 | 模拟量 / 混合型方案 | 兼容历史资产更容易 |
| 复杂 3C / 半导体样机平台 | 工业 PC + EtherCAT + 配置化架构 | 便于扩展与集成 |

### 选型时至少确认 6 件事

1. 真实需要控制多少轴，未来是否要扩轴
2. 是否需要 EtherCAT、远程 I/O、第三方编码器或安全模块
3. 现场节拍和同步精度要求是什么
4. SDK、示例、文档、驱动版本是否成熟
5. 团队更熟悉 PLC 思路、运动控制卡思路，还是 PC 软运动平台思路
6. 故障诊断能力是否足够支撑现场维护

## 第一套学习实验建议

如果你要带新人入门，建议先做一套最小实验平台：

- 1 套工业 PC 或普通开发 PC
- 1 张运动控制卡或 1 套 EtherCAT 入门平台
- 1 台伺服驱动器
- 1 台伺服电机
- 1 个原点开关
- 2 个限位开关
- 1 个急停按钮

实验目标只做 5 件事：

1. 连接设备
2. 使能驱动器
3. 回零
4. 点动
5. 绝对定位

只要这 5 件事稳定了，你再扩到双轴、插补和视觉，成功率会高很多。

## FAQ

### 1. 我是做上位机的，没有 PLC / 电气背景，能看懂吗？

可以。建议先按“`01 -> 03 -> 07 -> 04 -> 05`”顺序看，不要一开始就扎进厂商 SDK 细节。

### 2. 我应该先学某家控制卡 API，还是先学通用方法？

优先先建立通用方法。先理解建轴、回零、限位、状态机、日志和异常恢复，再看任何一家 SDK 都会快很多。

### 3. PCBase 是否等同于 EtherCAT？

不是。EtherCAT 是常见主线，但 PCBase 还包括脉冲型、模拟量和网络型控制架构。

### 4. 只会写运动指令，为什么项目还是很难交付？

因为真实项目还要处理安全链、报警、回零、联锁、配置管理、日志、验收与恢复流程。这些通常比单个 `Move` API 更关键。

### 5. 这些资料适合直接照搬到真实设备上吗？

不建议直接照搬。它们更适合做学习、评审、培训和架构参考，现场实施仍要结合具体硬件、电气图和安全规范二次确认。
